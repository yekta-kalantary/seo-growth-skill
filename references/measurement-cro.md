# Measurement and Organic CRO

Use when the goal includes proving SEO impact or improving conversion from organic landing pages.

## Measurement Plan

Start with the business decision and define:

- primary outcome and eligible users/sessions
- leading indicators: valid indexation, impressions, qualified query visibility, organic entrances
- behavioral diagnostics: engagement with meaningful page elements and next steps
- business outcomes: leads, revenue, signup, assisted conversion, retention/support deflection
- segments: page type, query intent, device, market, new/returning, branded/non-branded when data permits
- annotation date, comparison window, seasonality, releases, migrations, campaigns, and algorithm events

Use Search Console for search performance, analytics for on-site outcomes, and server/crawl data for discovery and technical health. Explain attribution limits when joining datasets.

## Organic Landing-Page CRO

Preserve intent satisfaction while improving conversion. Review message match from query/SERP to page, value proposition, proof, friction, mobile UX, speed, CTA relevance, and the information users need before acting.

Do not replace useful informational content with aggressive sales copy. Use contextual next steps appropriate to audience readiness.

## Experiments

State hypothesis, target population, primary metric, guardrails, implementation variant, duration/sample rationale, and stopping rule. Avoid declaring success from before/after movement alone when seasonality, ranking, traffic mix, or concurrent changes could explain it.

## Reporting

Pair every recommendation with an observable verification. Report absolute values and rates, sample size, period, segment, and uncertainty. Avoid vanity metrics without a link to the stated goal.
