# Search Research

Use for keyword research, intent analysis, current SERPs, content gaps, and competitor comparisons.

## Research Contract

1. Confirm search market, language, device/local context when relevant, business model, target conversion, and seed topic.
2. Inspect current SERPs for representative queries. Record date and market because results change.
3. Classify intent by dominant result types and tasks users are trying to complete, not by keyword wording alone.
4. Separate direct search competitors from business competitors.
5. Use supplied exports for volume, difficulty, traffic, or position metrics. Without them, mark demand and competition assessments as qualitative.

## Keyword Map

For each proposed target include:

| Field | Meaning |
|---|---|
| Primary query | One page's main demand expression |
| Variants/entities | Natural semantic coverage, not a stuffing list |
| Intent | Informational, commercial investigation, transactional, navigational, local, mixed |
| Funnel/job | User decision or task |
| SERP pattern | Dominant page types and features |
| Target page | Existing URL, refresh, merge, or new page |
| Business value | Direct, assisted, retention/support, low |
| Evidence | SERP observation or first-party/tool data |

Cluster by shared intent and SERP overlap. Similar wording alone is insufficient. When two queries produce substantially the same result set and serve the same task, prefer one strong page unless the business or locale requires separation.

## Competitor Analysis

Compare only dimensions relevant to the goal: positioning, page type, topic coverage, information gain, evidence, UX, internal linking, structured data, freshness, and conversion path. Identify replicable patterns and defensible differentiation; do not recommend copying headings or claims.

## Deliverables

- SERP/intent memo
- keyword-to-page map
- gap analysis: missing, weak, cannibalized, consolidate, protect
- opportunity backlog prioritized by business value, attainability evidence, effort, and dependency

## Failure Modes

- Calling autocomplete phrases verified search volume
- Treating a tool's difficulty score as universal truth
- Mapping every long-tail variant to a new page
- Comparing only title tags or word counts
- Claiming a competitor's traffic or conversions without a cited dataset
