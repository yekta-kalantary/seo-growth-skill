# AI Search: GEO, AEO, and LLM Visibility

Use for visibility and citations in AI answers, answer engines, AI Overviews, ChatGPT, Perplexity, Gemini, Copilot, and similar systems.

## Evidence First

AI products, retrieval sources, interfaces, and citation behavior change quickly. Browse current product documentation and run dated, repeatable query samples. Do not present platform-specific source-selection claims as permanent facts.

## Visibility Study

1. Define priority questions, market, language, audience stage, and platforms.
2. Run representative prompts consistently and record date, account/location assumptions, cited domains, cited URLs, answer themes, and brand presence.
3. Compare cited pages for direct answer quality, extractable structure, evidence, originality, freshness, entity clarity, and traditional crawl/index accessibility.
4. Separate citation visibility, unlinked brand mention, sentiment/positioning, and downstream conversion.

Prompt samples are observations, not stable rank tracking. Repeat over time and across variants before drawing strong conclusions.

## Optimization

- Make important claims clear, locally understandable, and supported by primary evidence.
- Use descriptive headings, concise answers, definitions, tables, examples, and explicit entity relationships where they improve comprehension.
- Publish original research, methodology, author/reviewer identity, dates, corrections, and source links.
- Maintain crawlability and traditional SEO foundations; AI visibility does not replace indexing, authority, or user value.
- Use structured data that accurately represents visible content.
- Treat `llms.txt` and other agent-readable formats as experimental unless current primary documentation establishes support for the target platform.

## Deliverable

Provide query set, dated observation table, citation-gap analysis, page-level improvements, authority/distribution opportunities, measurement plan, and explicit limitations. Never promise inclusion or citations.
